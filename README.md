# HVO.WebSite

Private repository for the HVO WebSite projects.

## Projects

| Project | Description |
|---|---|
| **HVO.WebSite.v9** | Main HVO website (Blazor SSR + API) |
| **HVO.WebSite.Playground** | Experimental playground site |
| **HVO.DataModels** | Entity Framework data models and DbContext |
| **HVO.NinaClient** | NINA astronomy software API client |
| **HVO.WebSite.Themes** | Shared CSS themes and fonts |
