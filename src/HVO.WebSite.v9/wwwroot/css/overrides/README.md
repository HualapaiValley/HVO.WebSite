# HVO.WebSite.v9 Overrides

Use this directory for site-specific stylesheet tweaks that extend the shared HVO dark theme.
Keep overrides minimal and prefer adding shared tokens to `HVO.WebSite.Themes` when the styling will
be reused by multiple applications.

Use [CSS governance](../../../../../docs/CSS_GOVERNANCE.md) and the
[shared Themes owner](../../../../HVO.WebSite.Themes/README.md) for tokens,
dark/light compatibility and website/ThemeSandbox sign-off. This folder has no
separate styling policy or release changelog.
